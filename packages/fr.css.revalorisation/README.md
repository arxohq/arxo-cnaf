# fr.css.revalorisation — Revalorisation (фаза 0: ряды INSEE)

Пакет канона CNAF (CNAF-REVALO, волна 0, задача W0-07): коэффициент
revalorisation ст. L. 161-25 CSS строится из ряда INSEE и сверяется с
опубликованным; тот же аппарат питает relèvement SMIC (декрет 2025-1228,
ст. 3 — индекс 1er quintile hors tabac).

## Мера готовности (§1.2 плана)

- Инвентарь: L. 161-25 CSS (текст — зеркало CSS, работа фермы W0-02);
  инструкции DSS в BO (W0-06, D-Q4/ферма); декрет 2025-1228 ст. 3 —
  закреплён в пакете `fr.travail.smic` (фрагмент DEC20251228_ART3).
- Источники: `sources/source-manifest.json`; байты INSEE Melodi
  (data.gouv.fr, организация INSEE): DS_IPC_PRINC 3 829 908 байт,
  DS_IPC_IND_CAT 7 224 байта, забраны 05.10.2026.
- Правила/сценарии: фаза W0-06 DONE 2026-10-06 — `02-bmaf.law`: цепочка
  BMAF(n) = BMAF(n−1) × коэффициент L. 161-25 с округлением до сантима
  (DECISION-0452) + планка коэффициента на единице (L. 161-25 абз. 2);
  `tests/bmaf-chaine-2026` (474,37 × 1,008 → 478,16 — ступень DSS-46) и
  `tests/bmaf-plancher` (0,995 → 1,0). `law test` 2/2.
- Текст L. 161-25 закреплён из дампа зеркала CSS (LEGIARTI000031781092,
  VIGUEUR с 2016-01-01; `sources/L161-25.txt`); инструкции DSS/2B/2026/46
  (01.04.2026) и DSS/2B/2025/177 (01.01.2026) — официальные байты PDF +
  извлечённый текст (`sources/dss-*.pdf/.txt`); фрагменты на коэффициент,
  BMAF, таблицы AF/надбавки и потолки. Пиннинг 7/0, CLIR
  `corpus/clir/fr-revalorisation.lawir.json`.
- Цепочка назад (D-24, 06.10.2026): апрель 2022–2025 (DSS/2B/2022/82,
  2023/41, 2024/43, 2025/38) + потолки январь 2022–2025 (DSS/2B/2021/247,
  DSS/SD2B/2022/283, DSS/2B/2023/205, DSS/2B/2024/181) — постраничные
  срезы из полных бюллетеней BO Santé (снимки Internet Archive `id_`,
  `tools/fetch_dss_bo.py`, происхождение — `sources/PROVENANCE.md`);
  фрагменты COEFF+BMAF и PLAFOND_AF+PLAFOND_CF дословные. Сценарии
  `tests/bmaf-chaine-2022…2025` (цепочка 414,81 → 422,28 → 445,93 →
  466,44 → 474,37 → 478,16 замкнулась из закреплённых байтов).
- История до 2015 (сессия 1 «Источники DSS», 08.10.2026): BMAF апрель
  2015–2021 и плафоны ресурсов январь 2015, 2017–2021 закреплены из байтов
  Internet Archive (срезы бюллетеней 2017.4, 2019.4, 2021.5, 2018.1,
  2019.1 и целые PDF отдельных инструкций сайта sante.gouv.fr — третий
  канал `tools/fetch_dss_bo.py`; дайджест SHA-1 каждого снимка сверен с
  индексом CDX архива). Теперь из закреплённых байтов берётся BMAF на любую
  дату 2015–2026 (цепочка 406,21 → 406,62 → 407,84 → [411,92] → 413,16 →
  414,4 → 414,81 → 422,28 → … → 478,16) и опубликованные плафоны на любую
  дату 2015–2026, кроме двух границ ниже. Сценарии `tests/bmaf-chaine-2016,
  2017, 2019, 2020, 2021` (всего сценариев пакета 12).
  - Инструкция BMAF 2018 (DSS/SD2B/2018/81, NOR SSAS1808080J) **не найдена**
    в архиве: значение 411,92 € закреплено косвенно текстом инструкции 2019
    («porté de 411,92 € à 413,16 €»); сценария 2018 нет (ставка и
    коэффициент 2018 в байтах не печатаются).
  - Инструкция плафонов на 01.01.2016 (DSS/SD2B/2015/371 du 18 décembre 2015)
    **не найдена**; единственное закреплённое свидетельство — текст
    инструкции 2017: суммы 2016 «reconduits à l’identique» на 2017
    (фрагмент `DSS_SD2B_2016_396_REVAL`).
  - BMAF 2015 (406,21 €, «maintenue»; коэффициента нет) закреплена без
    сценария: L. 161-25 в корпусе действует с 2016-01-01, правила `02-bmaf.law`
    раньше не срабатывают. Плафоны AF (модуляция введена с 01.07.2015) за
    2015 в закреплённых байтах отсутствуют: инструкция января 2015 содержит
    только CF/ARS/PAJE.
  - Ст. 9 закона 2022-1158 (коэффициент 1,04 на 01.07.2022 для всех сумм,
    индексируемых по L. 161-25) закреплена из дампа LEGI
    (`sources/loi-2022-1158-art9.txt`, `tools/pin_loi_2022_1158.py`, фрагмент
    `LOI_2022_1158_ART9`); сценарий `tests/bmaf-chaine-2022-07`
    (422,28 × 1,04 → 439,17). Число 439,17 **построено** цепочкой, ни одна
    закреплённая инструкция его не печатает (DSS/2B/2023/41 лишь вычитает
    «revalorisation anticipée de 4 %» из коэффициента 1,056); сценарий 2023
    остаётся от 422,28 × 1,056 → 445,93.
  - Инструкции 2016/77, 2017/97 печатают ставку (0,1 %; 0,3 % + коэффициент
    1,003), 2019/65 и 2020/33 — ставку дерогации +0,3 % (ст. 68 LFSS 2019,
    ст. 81 LFSS 2020), а не коэффициент; сценарии берут коэффициент как
    1 + ставка. Результат совпадает с опубликованным BMAF до сантима.
- Независимая сверка цепочки: ряд IPC_ENSEMBLE_M даёт
  mean(2025-02…2026-01)/mean(2024-02…2025-01) = 1,008317 → опубликовано
  1,008 (3 знака); 474,37 × 1,008 = 478,16496 → 478,16 (сантим).
  Округление публикаций — D-21.
- Остаток W0-07: ряд SMIC 2021–2025 (ферма: JORF global); инструкции DSS
  за 2015–2025 для цепочки назад — DONE (D-24 и сессия 1 08.10.2026);
  остаток: инструкция BMAF 2018 и плафоны 2016 (см. границы выше).

## Проверки

- `tools/fetch_insee_ipc.py --check` — ряды из байтов архивов (дубликат
  месяца или пустой фильтр = ошибка).
- `tools/fetch_dss_bo.py --check` — хэши срезов, целых PDF и кэша бюллетеней
  (офлайн); `--cdx` — сверка SHA-1 с индексом CDX Internet Archive (сеть).
- `tools/pin_loi_2022_1158.py --check` — текст ст. 9 закона 2022-1158.
- Слепое прочтение: BLIND_PENDING (второй модели в среде нет).
