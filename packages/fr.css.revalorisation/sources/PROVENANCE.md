# Происхождение закреплённых байтов DSS (D-24; сессия 1 «Источники DSS» от 08.10.2026)

## Три канала

1. **BO direct** (`bulletins-officiels.social.gouv.fr`, Safari UA): отдельные
   PDF инструкций текущего окна — `dss-2026-46.pdf` (NOR SFHS2607952J),
   `dss-2025-177.pdf` (NOR SFHS2535630J). Статус редакций —
   `PINNED_OFFICIAL_BYTES`.
2. **Internet Archive, полные бюллетени BO Santé** (`web.archive.org`, режим
   `id_` — исходные байты без обёртки): полные PDF бюллетеня
   (`https://sante.gouv.fr/fichiers/bo/YYYY/YYYY.N.sante.pdf` за 2021–2025 и
   `…/YYYY/YY-MM/ste_YYYYMMMM_0000_p000.pdf` старого сайта за 2017–2019;
   для 2019/4 — хост `solidarites-sante.gouv.fr`, снимок `sante.gouv.fr`
   обрезан). Прямой сайт старый архив не отдаёт (антибот `bobcmn`, challenge
   JS; новый сайт `bulletins-officiels` хранит только ~12 последних месяцев).
   Инструментом `tools/fetch_dss_bo.py` (pypdf 6.14.2, проверка `NOR : …`
   ровно 1 раз в срезе) из бюллетеня вырезаны постраничные PDF инструкций
   `sources/dss-YYYY-NNN.pdf` + текст `pdftotext -layout`. Полные бюллетени —
   в `sources/bo/.cache/` (в git не идут, воспроизводятся инструментом).
3. **Internet Archive, отдельные PDF инструкций** (канал `SINGLES` инструмента):
   файлы-статьи старого сайта BO Santé
   `https://sante.gouv.fr/fichiers/bo/YYYY/YY-MM/ste_YYYYMMMM_0000_NNNN.pdf`,
   снимок `id_` хранится **целиком**, без нарезки
   (`sources/dss-YYYY-NNN.pdf`), рядом — `pdftotext -layout`.
   Проверяются размер, SHA-256, NOR (ровно один раз), маркер заголовка и
   дайджест CDX (см. ниже).

Статус редакций каналов 2 и 3 — `PINNED_UNOFFICIAL_COPY` (прецедент:
`us/social-security-1935-1939`, производная копия официальных байтов; байты
получены в режиме `id_` и совпадают по SHA-1 с индексом CDX архива).

`sources/loi-2022-1158-art9.txt` — статья 9 закона n° 2022-1158 du 16 août 2022
(JORFTEXT000046186723 / LEGITEXT000046188434, NOR ECOX2217989L),
LEGIARTI000046188473, версия VIGUEUR с 2022-08-18; учёт (путь в дампе, SHA-256
XML и текста) — `sources/loi-2022-1158-art9.json`; извлечение —
`tools/pin_loi_2022_1158.py` (`--write` читает дамп, `--check` сверяет текст).
Статья устанавливает коэффициент 1,04 на 1 июля 2022. Статус редакции —
`PINNED_UNOFFICIAL_COPY`, окно `in_force` редакции начато 2022-07-01 (день
применения коэффициента), а не датой консолидированной версии.

## Что проверено о подлинности копий

- Байты получены в режиме `id_` (без обёртки архива); каждый бюллетень —
  валидный PDF 1.5–1.7, колонтитулы «BO Santé – Protection sociale –
  Solidarité», сквозная пагинация совпадает с номером бюллетеня.
- **Сверка с индексом CDX Internet Archive выполнена 08.10.2026**: дайджест
  CDX (`digest` = base32 SHA-1 байтов снимка) совпал с SHA-1 локальных байтов
  для всех 7 целых PDF и для всех 13 бюллетеней (`cdx_sha1_b32` в
  `source-manifest.json`; повторная сверка по сети —
  `tools/fetch_dss_bo.py --cdx`, офлайн — `--check`). Это закрывает оговорку
  D-24 от 06.10.2026 (сбой сервиса).
- Каждый срез и целый PDF содержит ровно один NOR, совпадающий с номером
  инструкции; заголовки (дата подписи, объект) согласуются с цитатами этих
  инструкций в инструкциях следующих лет: 414,4 → 414,81 (2021) подтверждено
  инструкцией 2022/82; 411,92 → 413,16 (2019) и 413,16 → 414,4 (2020)
  сходятся в цепочку; 406,21 → 406,62 → 407,84 цитируются в 2016/77 и 2017/97.
- Арифметика цепочки проверена сценариями `tests/bmaf-chaine-2016…2026`
  (BMAF(n−1) × коэффициент, округление до сантима).

## Артефакты извлечения

- `dss-2021-247.txt`, NB под таблицей AF: разрыв «plafond de base d e /
  58 396 euros» — артефакт раскладки `pdftotext -layout`, числа
  однозначны (58 396 / 5 839 / 81 721). Фрагмент — дословный срез.
- `dss-2016-396.txt`, таблица CF: в оригинале «1 enfant … 4 604»
  (биактивность) — опечатка источника при 34 604; фрагмент
  `…_2016_396_PLAFOND_CF` содержит только базу и majorations, где опечатки нет.
- `dss-2017-352.txt`, majorations CF: в строках есть символы табуляции из
  PDF; фрагмент `…_2017_352_PLAFOND_CF` дословный, с табуляциями.
- Таблицы AF/CF — дословно с пробельной раскладкой, как пины 2025/177.
- Инструкции 2016/77 и 2017/97 печатают **ставку** (0,1 %), а 2019/65 и 2020/33
  — **ставку дерогации** (+0,3 %, ст. 68 LFSS 2019 и ст. 81 LFSS 2020), а не
  коэффициент; сценарии берут коэффициент как 1 + ставка (1,001; 1,003; 1,003).
  Результат совпадает с опубликованным BMAF до сантима.
