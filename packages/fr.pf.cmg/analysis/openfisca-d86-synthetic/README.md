# D-86: воспроизводимые синтетические пробы CMG

`replica.py` запускает частную симуляцию OpenFisca-France 176.1.2 из закреплённого checkout `16b2e69633e840fdf5f39b74f96dfd2382898dd5` в `.scratch/openfisca-france`. Команда из корня репозитория: `PYTHONPATH=.scratch/openfisca-france .scratch/of-venv/bin/python corpus/laws/fr/pf-cmg/analysis/openfisca-d86-synthetic/replica.py`. Зафиксированный вывод — `results.json`; исходный журнал прогона — `.scratch/fr-cnaf-run/d86-L2-of-probe.log`. Скрипт не правит общий отчёт, CLIR или пакет.

Два входа: один родитель, один ребёнок, `ass_mat`, апрель/июнь/сентябрь 2024. Ресурсы `prestations_familiales_base_ressources` задаются непосредственно, чтобы отделить формулу CMG от вычисления доходов. Их результат — только ожидание сравнения, не источник нормативных чисел.

1. Ребёнку 4 года, ресурсы 31 261 €. D. 531-23 3° требует +40 % к плафонам одинокого родителя (`corpus/laws/fr/pf-cmg/sources/fr-pf-cmg/D531-23-ed2021.txt:18`). DSS печатает 27 401 + 4 532 = 31 933 € и 60 887 + 10 073 = 70 960 € (`corpus/laws/fr/revalorisation/sources/dss-2023-205.txt:346-371`); обычный плафон 19 572 + 3 237 = 22 809 € (`corpus/laws/fr/revalorisation/sources/dss-2023-205.txt:321-343`). Наш максимум: полоса 1, 1,7257 × 466,44 / 2 = 402,467754 → **402,47 €**. BMAF 466,44 € закреплена в `corpus/laws/fr/revalorisation/sources/dss-2024-43.txt:183`. Их код `openfisca_france/model/prestations/prestations_familiales/paje.py:631-642` не применяет параметр +40 %; реплика выбирает полосу 2 и даёт **335,39368 €** = 1,4381 × 466,44 / 2 до float32. Класс (б).
2. Ребёнок родился 2021-01-01, ресурсы 80 000 € (полоса 3 по обоим плафонам). L. 531-5 IV сохраняет полную выплату до конца августа для январского–августовского третьего дня рождения (`corpus/laws/fr/pf-cmg/sources/fr-pf-cmg/L531-5-ed2020.txt:23`); L. 531-6 распространяет условие на структуру (`corpus/laws/fr/pf-cmg/sources/fr-pf-cmg/L531-6-ed2020.txt:10`). Наш максимум в апреле/июне: 1,1505 × 466,44 = 536,639220 → **536,64 €**; в сентябре половина **268,32 €**. Их `paje.py:654-658` делит с возраста 3 уже в апреле/июне; реплика даёт **268,3196 €** во все три месяца. Класс (б) до сентября.

`results.json` хранит входы, числа и ссылки на закреплённые источники. Числа в скрипте OpenFisca используются только как предъявленные факты синтетического дела; опубликованные плафоны и BMAF взяты из указанных текстов.

Месячный срез: возраст в деле предъявлен на первое число месяца. L. 552-1 (`corpus/laws/fr/pf-core/sources/css/L552-1.txt:2`) относит изменения прав к правилам открытия/прекращения; R. 552-3 II 1° (`corpus/laws/fr/pf-core/sources/css/R552-3.txt:2-4`) для CMG указывает первое число месяца после отпадения условий. Эти нормы поддерживают раздельный разбор месячного права и даты рождения, но точный переход суммы при дне рождения посреди месяца здесь не формализован как самостоятельное правило выплаты: сценарий 15 сентября → срез 1 октября показывает последовательные входные факты возраста.
